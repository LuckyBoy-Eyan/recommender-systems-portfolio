# MiniTIGER 正式实验结果

## 评估协议

- KuaiRec Big Matrix：7,174 用户、9,438 视频、6,309,308 条正反馈；
- 每个用户倒数第二条作为验证目标，最后一条作为测试目标；
- 训练只读取更早的历史，推荐时屏蔽已看商品；
- 验证集选择最佳 epoch 和精排参数，测试集不参与选择；
- 生成模型与 SASRec 均约 163 万参数；
- 每条测试样本只有一个正例，因此 Recall 与 HitRate 相同。

## 最终结果

| 系统 | Recall@5 | Recall@10 | Recall@20 | NDCG@20 |
|---|---:|---:|---:|---:|
| 纯生成模型 | 0.094926 | 0.139113 | 0.196822 | 0.095620 |
| 生成 + SASRec 固定融合 | 0.105520 | 0.150962 | 0.213131 | 0.104453 |
| 生成 + 学习式精排 | **0.105799** | **0.151798** | **0.213688** | **0.104760** |

生成 Top-200 候选 Recall 为 `0.561890`。学习式精排不会改变候选覆盖，只负责
优化候选内部顺序。

## Semantic ID 质量

| 指标 | 结果 |
|---|---:|
| 完整编码碰撞率 | 0 |
| 第一级 Token 利用率 | 100% |
| 第二级 Token 利用率 | 100% |
| 第三级 Token 利用率 | 100% |
| Exact Recall@200 | 0.561890 |
| Beam=500 Recall@200 | 0.561890 |

Exact 与 Beam 完全相同，说明 Beam 剪枝不是主要瓶颈。逐级诊断显示第一级
Token 的 Top-1 约为 `9%`、中位排名约为 `13`，而后续层明显更容易预测。

## 等容量与 Behavior-RQ

| 编码 | Candidate Recall@200 |
|---|---:|
| 等容量旧 RQ | 0.562169 |
| Behavior-aware RQ | 0.561890 |

Behavior-aware RQ 没有提高候选覆盖，但它满足零碰撞、全码本利用和与 SASRec
等容量的实验控制要求。最终保留它作为完整工业流水线实现，但不把差异表述为
显著性能提升。

## 未进入最终系统的实验

| 实验 | Exact Recall@200 | Test Recall@20 |
|---|---:|---:|
| 第一级损失权重 ×2 | 0.539309 | 0.179398 |
| SASRec 粗 Token 蒸馏 | 0.539030 | 0.182743 |

SASRec 教师自身第一级 Top-1 为 `18.40%`，但蒸馏学生只有 `8.92%`。说明教师
信号有效，当前固定路由和学生训练方式却没有成功吸收该知识。继续使用相同损失
加权或 KL 蒸馏意义不大。

## 结论

1. 生成式 Semantic ID 能构成完整、合法且可精排的候选召回链路；
2. SASRec 候选精排将 Recall@20 从 `0.1968` 提高到 `0.2131`；
3. 学习式精排带来小幅稳定增益；
4. 当前主要上限来自第一级路由，而不是 Beam Search；
5. 下一阶段应研究可学习、负载均衡的粗路由，或更强的生成历史编码器。
