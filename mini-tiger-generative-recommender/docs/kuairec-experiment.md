# KuaiRec 实验协议

## 数据与标签

KuaiRec Big Matrix 包含 7,174 个用户、9,438 个视频和 12,487,057 条交互。观看比例
`>=0.7` 且播放时长 `>=5s` 定义为正反馈，其余有效交互定义为负反馈。

每位用户的交互严格按时间排序。输入序列保留全部正负事件，并使用 Feedback Type Embedding
显式区分；训练只在正反馈目标上计算损失。验证目标是倒数第二个正反馈，测试目标是最后一个
正反馈，因此负事件不会被错误选为评价目标。

## Fair100

MiniTIGER 与 SASRec 均只使用每位用户最近至多 100 个训练正目标，共 716,169 个目标；最大
历史长度均为 100，统一以验证集 HR@200 早停。SASRec 也保留完整正负上下文，仅屏蔽负目标
位置的监督。

每个验证或测试样本只有一个正目标，因此 Recall@K 与 HitRate@K 数值相同，本文统一使用：

- HR@K：目标是否进入前 K；
- NDCG@K：按命中位置折损；
- MRR@K：命中位置的倒数；
- AUC/UAUC：全目录正目标相对负物品的排序能力，仅作辅助指标。

模型选择只依据验证集。测试集已用于阶段性补评，不能再视为未触碰的盲测集。
