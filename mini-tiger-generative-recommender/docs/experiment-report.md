# MiniTIGER 全量实验报告

## 1. 实验目标

本项目验证基于 Semantic ID 的自回归生成模型能否完成下一物品召回。主模型不使用 SASRec
物品向量，也不包含第二阶段精排；SASRec 仅作为独立基线。最终输出是一份按生成概率排序的
Top-K 物品列表。

## 2. 数据集与反馈定义

实验使用 KuaiRec Big Matrix：

| 项目 | 数量 |
|---|---:|
| 用户 | 7,174 |
| 视频 | 9,438 |
| 有效交互 | 12,487,057 |
| 正反馈 | 6,309,308 |
| 负反馈 | 6,177,749 |

正反馈定义为观看比例不低于 0.7 且播放时长不低于 5 秒，其他有效交互定义为负反馈。

每位用户的交互按时间戳排序。输入侧保留完整正负序列，并加入 Feedback Type Embedding；
输出侧只监督正反馈目标。负反馈不是 Padding：它可以被注意力读取并通过后续正目标损失获得
间接梯度，但不会被模型当作需要生成的目标。

## 3. 时间切分与 Fair100

切分围绕正目标进行：倒数第二个正反馈为验证目标，最后一个正反馈为测试目标，目标发生之前
的全部正负交互构成上下文。任一目标时间点之后的信息均不得进入该样本。

Fair100 将 MiniTIGER 与 SASRec 的训练目标统一为每位用户最近至多 100 个正目标：

| 项目 | MiniTIGER | SASRec Fair100 |
|---|---:|---:|
| 正训练目标 | 716,169 | 716,169 |
| 最大历史长度 | 100 | 100 |
| 早停指标 | HR@200 | HR@200 |
| Patience | 10 | 10 |

SASRec 同样保留完整正负上下文，只在选定正目标位置计算损失。旧版 positive-only SASRec 与
All-Targets SASRec 因数据协议或监督规模不同，不作为最终公平结论依据。

## 4. 内容 Embedding

每个视频将标题和多级类目拼成文本，例如：

```text
title: 篮球精彩集锦; category_1: 体育; category_2: 篮球
```

Sentence-T5 Base 将文本编码为 768 维向量。向量经过 PCA 降至 128 维，PCA 不使用 whitening，
降维后执行 L2 归一化。最终 SID 是纯内容路线，用户行为只交给序列模型建模。

## 5. RQ-KMeans 与碰撞处理

RQ-KMeans 依次量化当前残差，得到三级语义前缀 `<c1,c2,c3>`。最终码表从 `[64,64,64]`
调整为 `[128,64,32]`，在不改变 262,144 理论容量的情况下增加第一层语义粒度。

最终 `[128,64,32]` 诊断：

| 层级 | 容量 | 使用数 | 利用率 | 归一化熵 | 最大桶 |
|---|---:|---:|---:|---:|---:|
| C1 | 128 | 128 | 100% | 0.9870 | 93 |
| C2 | 64 | 64 | 100% | 0.9682 | 185 |
| C3 | 32 | 32 | 100% | 0.9495 | 369 |

9,438 个物品形成 5,218 个不同三级前缀，因此有 4,220 个额外物品需要消歧，前缀碰撞率为
44.71%。同前缀组内追加局部 tail 编号：

```text
item A -> <12,31,7,0>
item B -> <12,31,7,1>
```

Tail 不承担主要语义，只负责将完整 SID 唯一映射回物品。Tail 容量为 60；加入 Tail 后共有
9,438 个唯一完整 SID，完整碰撞率为 0。

类目诊断显示第一层类别 NMI 分别为 0.4675、0.5183 和 0.5537（对应三种类目层级），同类
物品共享前缀的概率显著高于异类物品，说明 SID 具有中等到较强语义信号，并非随机编码。

## 6. MiniTIGER 架构

历史中每个物品的表示为各层 SID Embedding、Feedback Type Embedding 和 Position Embedding
之和。Encoder 读取完整历史，Decoder 自回归生成：

```text
c1 -> c2 -> c3 -> tail
```

最终 L6 参数：

| 参数 | 数值 |
|---|---:|
| Hidden | 256 |
| Encoder Layers | 6 |
| Decoder Layers | 6 |
| Heads | 4 |
| FFN | 1,024 |
| Dropout | 0.1 |
| 最大历史 | 100 |
| Batch Size | 256 |
| 初始学习率 | 3e-4 |
| Warmup | 2 epochs |
| 最低学习率 | 1e-5 |
| 最大轮数 | 100 |
| 最佳检查点 | Epoch 11 |
| 停止轮次 | Epoch 21 |

优化器采用 AdamW、Weight Decay 0.01、Cosine 学习率衰减和梯度裁剪 1.0。工程侧支持 FP16、
fused AdamW、断点续训及批量 Beam 评估。

## 7. 受限生成与评价

训练使用 Teacher Forcing，只对目标 SID 的四个 token 计算交叉熵。推理使用 Trie 约束 Beam
Search，只允许生成 9,438 个有效 SID 的合法前缀。候选按累计 log-probability 排序；当前没有
独立排序模型，也没有 MiniTIGER/SASRec 分数融合。

每个样本只有一个测试正目标，因此 Recall@K 与 HitRate@K 数值相同，项目统一报告 HR@K。
HR 衡量覆盖，NDCG/MRR 衡量头部位置，AUC/UAUC 评价全目录正负区分能力。

## 8. 模型演进

| 模型 | SID | Hidden | Enc/Dec | 验证 HR@200 | 验证 NDCG@20 | 验证 MRR@20 |
|---|---|---:|---:|---:|---:|---:|
| 原始 MiniTIGER | `[64,64,64]` | 192 | 3/3 | 0.6048 | **0.1169** | **0.0855** |
| MiniTIGER L4 | `[128,64,32]` | 256 | 4/4 | **0.6171** | 0.1140 | 0.0818 |
| MiniTIGER L6 | `[128,64,32]` | 256 | 6/6 | 0.6098 | 0.1160 | 0.0846 |

L4 和 L6 的 Batch Size、学习率阶段及调度并未完全控制一致，因此不能把差异解释为严格的层数
消融。L4 的验证 HR@200 更高；项目最终选择 L6，是偏向其恢复后的头部 NDCG/MRR，而不是
因为它具有最高召回覆盖。

## 9. 最终公平结果

### 验证集

| 模型 | HR@20 | HR@200 | NDCG@20 | MRR@20 |
|---|---:|---:|---:|---:|
| SASRec V2 Fair100 | **0.2321** | **0.6360** | 0.1127 | 0.0790 |
| MiniTIGER L6 | 0.2280 | 0.6098 | **0.1160** | **0.0846** |

### 测试集

| 模型 | HR@20 | HR@200 | HR@500 | NDCG@20 | MRR@20 | AUC/UAUC |
|---|---:|---:|---:|---:|---:|---:|
| SASRec V2 Fair100 | **0.2280** | **0.6140** | **0.8372** | 0.1101 | 0.0769 | **0.9696** |
| MiniTIGER L6 | 0.2234 | 0.5891 | 0.8032 | **0.1150** | **0.0848** | 0.9628 |

MiniTIGER L6 相对 SASRec 的测试 NDCG@20 提升约 4.4%，MRR@20 提升约 10.3%；SASRec 的
HR@20/200/500 均更高。结论是 SASRec 候选覆盖更强，而 MiniTIGER 的命中更集中在头部，
不能表述为 MiniTIGER 全面优于 SASRec。

L6 的 Beam=500 与 Exact 在 HR@5 至 HR@500 上完全一致，NDCG/MRR 只有浮点级差异，说明
Beam=500 已基本恢复该模型的 Exact Top-500 排名。

## 10. 结果边界与后续方向

- 测试集已用于阶段性分析和 Beam=500 补评，不能再视为完全未触碰的盲测集；
- Tail 依赖仍然较高，下一步可固定其他变量测试 `[128,64,64]`；
- 若第三层扩容不能明显降低前缀碰撞，应优先改进文本特征与 PCA，而不是继续增深模型；
- 未来若加入精排或融合，必须作为独立阶段重新训练和报告，不能写入当前结果。
